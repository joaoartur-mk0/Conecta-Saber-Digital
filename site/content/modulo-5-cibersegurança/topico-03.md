# Sites Falsos, Spoofing e Links Maliciosos #

Uma das estratégias utilizadas em golpes digitais é criar páginas que imitam sites conhecidos.

Essas páginas podem apresentar logotipos, cores e textos semelhantes aos utilizados por empresas ou órgãos públicos.

## O que é Spoofing?

> **Spoofing** é uma técnica utilizada para fazer uma comunicação, endereço ou página parecer pertencer a uma fonte legítima.

Em golpes envolvendo sites, o criminoso pode criar uma página falsa para tentar obter:

- Nome;
- CPF;
- Senha;
- Dados bancários;
- Informações de cartão;
- Códigos de autenticação.

## Como Identificar um Site Suspeito?

Antes de informar qualquer dado, observe:

### 1. Endereço do site

Confira cuidadosamente o endereço exibido no navegador.

Uma pequena alteração no endereço pode indicar que você está em um site diferente do original.

### 2. Domínio

No caso de serviços do Governo Federal, os canais oficiais utilizam o domínio **gov.br**.

Golpistas podem criar páginas visualmente semelhantes às oficiais para induzir o usuário ao erro. :contentReference[oaicite:4]{index=4}

### 3. Mensagens de urgência

Tenha cuidado com frases como:

> "Última oportunidade."

> "Sua conta será bloqueada."

> "Pague agora para evitar problemas."

### 4. Solicitação de informações

Desconfie quando uma página inesperada solicita:

- Senha;
- Código recebido por SMS;
- Dados bancários;
- Informações pessoais;
- Pagamento.

## Links Maliciosos

Um link recebido por mensagem pode direcionar para uma página falsa.

Por isso, evite clicar automaticamente em links enviados por desconhecidos ou em mensagens inesperadas.

Quando precisar acessar um serviço importante, uma alternativa mais segura é abrir o navegador e acessar diretamente o canal oficial da instituição.

## Exemplo

Uma pessoa recebe pelo WhatsApp:

> "Existe uma pendência em seu CPF. Clique aqui para regularizar."

Em vez de clicar no link, a pessoa deve:

1. Não clicar;
2. Verificar a mensagem;
3. Procurar o órgão diretamente;
4. Acessar o canal oficial;
5. Consultar se realmente existe alguma pendência.

## Aula Prática

### Apresentação da atividade

Nesta atividade, os participantes deverão analisar endereços de sites fictícios e identificar possíveis sinais de fraude.

#### Atividade

Para cada endereço apresentado pelo professor, observe:

- Nome do domínio;
- Ortografia;
- Presença de caracteres estranhos;
- Uso de HTTPS;
- Solicitação de informações;
- Mensagem apresentada na página.

Depois, responda:

**Você confiaria nesse site? Por quê?**

> O objetivo da atividade é desenvolver o hábito de verificar o endereço e a origem de uma página antes de inserir informações.
