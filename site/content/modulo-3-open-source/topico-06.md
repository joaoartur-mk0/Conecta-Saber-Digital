| Palavras Chaves |
|---|---|
>- Open Source: Modelo de software com código aberto.
>- Software Livre: Programa que pode ser utilizado, estudado, modificado e 
compartilhado. 
>- PDF: Formato de documento portátil. 
>- ZIP: Arquivo compactado que reduz espaço de armazenamento. 
>- HTTPS: Protocolo seguro utilizado por sites. 
>- Código-fonte: Conjunto de instruções que formam um programa. 
>- Troubleshooting: É um termo em inglês que significa solução de problemas, 
diagnóstico e correção de falhas.
