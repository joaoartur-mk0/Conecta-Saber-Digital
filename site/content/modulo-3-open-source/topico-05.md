 ## Cenário 1: Você encontrou um programa gratuito em um site desconhecido. 
 # O que fazer? : 

>- Verificar o endereço do site.  
>- Pesquisar a reputação do software.  
>- Procurar a página oficial do desenvolvedor.  
>- Comparar a versão disponível antes do download.  



 ## Cenário 2:  Um estudante precisa criar uma apresentação para um seminário, mas não possui programas pagos. 
 # O que fazer? : 

>- Instalar uma suíte de escritório gratuita.  
>- Utilizar o LibreOffice Impress para criar os slides.
>- Salvar o arquivo em formato compatível (.pptx ou .pdf). 
>- Testar a apresentação antes da exposição. 





 ## Cenário 3: Um usuário recebeu um arquivo compactado (.zip) e precisa acessar seu conteúdo. 
 # O que fazer? : 

>- Verificar a origem do arquivo recebido.  
>- Utilizar um descompactador confiável.  
>- Extrair os arquivos para uma pasta específica.    
>- Verificar os documentos antes de executá-los.   



 ## Cenário 4: Um usuário precisa compartilhar um arquivo grande com colegas de trabalho. 
 # O que fazer? : 

>- Compactar o arquivo para reduzir seu tamanho.    
>- Utilizar um serviço de armazenamento em nuvem. 
>- Compartilhar o link de acesso.   
>- Verificar as permissões de visualização e edição.
